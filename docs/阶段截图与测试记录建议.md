## 测试命令记录

建议在总报告测试章节记录以下命令和结果：

```powershell
npm run lint
npm run build
npm run smoke
```

`npm run smoke` 需要先启动开发服务：

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

如果使用其他端口，可以设置：

```powershell
$env:SMOKE_BASE_URL='http://127.0.0.1:5174'; npm run smoke
```

## DeepSeek API 演示记录

真实 API 演示前，在 `.env` 中配置：

```text
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
VITE_DEEPSEEK_MODEL=deepseek-v4-flash
VITE_DEEPSEEK_USE_PROXY=true
```

配置后重启开发服务，再访问 `/reports` 点击“AI 生成分析小结”。截图时注意不要展示真实 API Key。
