## 测试命令记录

建议在总报告测试章节记录以下命令和结果：

```powershell
npm run lint
npm run build
npm run smoke
```

`npm run smoke` 需要先启动开发服务：

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

如果使用其他端口，可以设置：

```powershell
$env:SMOKE_BASE_URL='http://127.0.0.1:5174'; npm run smoke
```
